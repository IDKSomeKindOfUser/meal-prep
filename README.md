# Prepka

Prepka собирает меню на неделю или на четыре недели, список покупок и план готовки. Я делаю его для себя: готовлю два раза в неделю и планирую чаще всего с телефона, на кухне или прямо в магазине.

Сайт: https://meal-prep-orpin-one.vercel.app

Вводишь пол, возраст, рост, вес, сколько раз в неделю готовишь и сколько готов потратить. Сайт считает норму калорий и белка и подбирает блюда, которые не нарушают ограничений и укладываются в чек. Продукты считаются целыми пачками: остаток пачки переходит на следующую неделю внутри месяца. Срок хранения и заморозку сайт тоже учитывает.

## Что умеет

- 162 рецепта (51 завтрак, 82 обеда и ужина, 29 перекусов) из 79 продуктов. У каждого блюда есть фото.
- Аллергены, исключённые продукты, острое и нужную технику сайт не нарушает никогда.
- «Сегодня» показывает блюда дня и что готовить, «Неделя» умещает дни в строки с миниатюрами.
- В разделе «Рецепты» собраны все блюда, даже те, что не попали в меню. Есть поиск по названию и фильтр по типу. Если блюдо не подходит под анкету, рядом написано почему: аллерген, лактоза, нет нужной техники или оно не пролежит до следующей готовки. Новые блюда первую неделю идут первыми с меткой «Новое».
- Блюдо можно заменить: сайт предложит варианты и покажет, как изменятся калории и чек. Замена действует на все дни, которые готовятся вместе.
- Перед пересборкой меню сайт задаёт несколько коротких вопросов: какое мясо хочется, какие блюда. Новое меню отличается от старого в каждой готовке, а прежнее можно вернуть из уведомления.
- Обед и ужин в один день всегда разные.
- Покупки разбиты на «Рынок» и «Магазин» и по отделам. Купленное зачёркивается, список можно скопировать.
- «Готовка» расписывает день готовки по порядку: что поставить первым, что делать, пока запекается, как разложить по контейнерам.
- В рецепте шаги отмечаются галочкой, время в шаге запускает таймер, экран не гаснет.
- Можно добавить свои рецепты и поправить цены продуктов.
- Светлая и тёмная тема, телефон и компьютер. Сайт ставится как приложение и работает без сети.
- Вход нужен только для синхронизации между устройствами.

Меню подбирается прямо в браузере, без нейросети. Калории посчитаны по справочным данным, сайт об этом предупреждает.

## Как устроено

React, Vite и TypeScript. Данные и вход хранятся в Supabase, хостинг на Vercel. Шрифты Playfair Display (заголовки) и Sofia Sans (текст) лежат в проекте, иконки из `lucide-react`.

- `src/planner/` собирает меню: отбирает подходящие блюда, подгоняет порции под норму и ищет дешёвый и разнообразный набор отжигом (simulated annealing). Здесь же считаются покупки и стоимость.
- `src/data/` хранит рецепты, продукты, цены и список фото.
- `src/app/` содержит экраны, хранение в браузере и синхронизацию. Подбор меню идёт в Web Worker, чтобы экран не подвисал.
- `public/photos/` хранит фото блюд. Почти все взяты с кулинарных сайтов, два с Wikimedia Commons. Источники перечислены на странице `#credits`.
- `supabase/schema.sql` создаёт таблицу и правила доступа: каждый пользователь видит только свои строки.
- `scripts/` содержит вспомогательные скрипты: подбор и сборку фото (`photos.py` для Wikimedia, `web_photos.py` для фото из поиска Bing), иконки, офлайн-сборку.

## Запуск

```
npm install
npm run dev
```

Тесты и сборка:

```
npm test
npm run build
```

Тесты проверяют и данные: КБЖУ рецепта сходится с суммой по составу, порции держатся в своих рамках, аллергены в специях отмечены.

## Синхронизация

Без неё сайт тоже работает, всё хранится в браузере. Чтобы её включить, создай проект в Supabase, выполни `supabase/schema.sql` в редакторе запросов и положи адрес и публичный ключ в `.env.local` по образцу `.env.example`:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_KEY=
```

Ключ нужен публичный (publishable). Секретный ключ в проект не кладём.

При конфликте побеждает более новая правка. Данные одного аккаунта под другим не отправляются.
